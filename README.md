# SpireX Foundation Internship – Tasks

This repository contains the tasks completed as part of the **SpireX Foundation Internship – Advanced Session** using HTML, CSS, and JavaScript.

## Task 1: Personal Portfolio Card

A responsive personal portfolio card built using HTML, CSS, and JavaScript to showcase personal information, skills, and professional links.

## Task 2: Digital CV / Resume Card

A professional and responsive CV/Resume card built using HTML, CSS, and JavaScript. It presents educational background, technical skills, internship experience, projects, and contact information in a clean and structured layout.

### Technologies Used

- HTML5
- CSS3
- JavaScript

### Features

- Responsive design
- Clean and professional UI
- Clickable contact links
- Interactive elements
- Print / Save as PDF functionality
